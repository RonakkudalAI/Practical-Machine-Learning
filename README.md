# Practical Machine Learning

A collection of practical Machine Learning implementations, experiments, and practice sets covering fundamental and advanced ML concepts using Python and Scikit-learn.

## 📚 Topics Covered

### Supervised Learning
- Linear Regression
- Ridge Regression
- Lasso Regression
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Support Vector Regression (SVR)
- Decision Tree
- Random Forest
- Naive Bayes

### Unsupervised Learning
- K-Means Clustering
- Hierarchical Clustering
- DBSCAN
- Isolation Forest

### Dimensionality Reduction
- Principal Component Analysis (PCA)

### Model Implementation
- Classification
- Regression
- Clustering
- Model Training
- Model Evaluation
- Hyperparameter Tuning
- Practical ML Experiments

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
